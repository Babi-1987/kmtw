# kmtw — Belajar Web3

Website edukasi Web3 berbahasa Indonesia, dengan direktori marketplace Ethereum, Solana, dan Bitcoin/Ordinals.

## Menjalankan

Gunakan Node.js 22 atau lebih baru. Jalankan `npm install`, lalu `npm run dev`.
Build produksi: `npm run build`.

## Vercel

Hubungkan repository ini ke proyek kmtw-vercel yang sudah ada.
Framework preset: Next.js. Root Directory: root repository (./).
Build command: npm run build. Output Directory: default Next.js.
Tidak membutuhkan environment variables atau database untuk website edukasi ini.
